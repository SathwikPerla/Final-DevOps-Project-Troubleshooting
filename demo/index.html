Automated CI/CD Delivery Pipeline (GitHub Actions)

Stage 1: Test & Build 24s Runtime
  • Executes on push to main branch.
  • Spawns Ubuntu runner with Python 3.12 and Node.js 22.
  • Runs pytest -v against backend.
  • Compiles production React frontend assets (npm run build).
Stage 2: Scan & Push 1m Runtime
  • Builds backend and frontend Docker images.
  • Tags images with immutable git commit SHA (${{ github.sha }}).
  • Runs Trivy vulnerability scanning on both containers.
  • Pushes verified packages to GitHub Container Registry (ghcr.io).
Stage 3: Deploy 5s Runtime
  • Initializes Helm 3 and configures kubectl.
  • Executes atomic helm upgrade --install sevzero ./helm/sevzero.
  • Updates image tags dynamically with commit SHA.
  • Zero-downtime rolling update across Kubernetes pods.
