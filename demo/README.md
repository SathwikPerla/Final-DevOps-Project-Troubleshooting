# SevZero — Project Demonstration & Presentation Deliverables

This directory contains the demonstration media, presentation decks, and evaluation links for the **SevZero** DevOps Capstone Project.

---

## 🎬 Project Video Walkthrough

The comprehensive end-to-end video walkthrough showcases the complete DevOps lifecycle:
1. **Application UI & Flow:** FastAPI backend and responsive React frontend running locally.
2. **Automated Testing Suite:** 12/12 passing Pytest tests with unit and integration coverage.
3. **Containerization:** Multi-stage, unprivileged non-root Docker builds and Docker Compose orchestration.
4. **Kubernetes Orchestration:** Live cluster validation (Pods, Services, Ingress, HPA, ConfigMaps, Secrets).
5. **DevSecOps CI/CD Pipeline:** GitHub Actions workflow with automated test validation, Trivy container security vulnerability scanning, GitHub Container Registry (GHCR) image publishing, and Helm deployment templates.
